# Straw Bed Mod

A NeoForge 1.26.1 mod that adds a Straw Bed to Minecraft with unique sleeping mechanics.

## Features

✨ **Sleep Through the Night** - The Straw Bed allows players to sleep and skip the night.

🛏️ **No Spawn Point** - Sleeping in a Straw Bed does NOT set your spawn point.

💥 **One-Time Use** - The Straw Bed breaks after a successful night's sleep.

🌎 **Safe in Any Dimension** - Works safely in the Nether and the End without any issues.

🧵 **Easy Crafting** - Craft from 6 hay bales in a 3x2 pattern.

## Crafting Recipe

```
H H H
H H H
```

Where H = Hay Bale

Result: 1x Straw Bed

## Installation

1. Download the latest JAR file from the releases
2. Place it in your `mods` folder
3. Launch Minecraft with the NeoForge 1.26.1 loader

## How to Use

1. Craft a Straw Bed using hay bales
2. Place it in the world
3. Right-click the bed to sleep
4. The night will pass as normal
5. After you wake up, the Straw Bed will break

## Technical Details

- Built with NeoForge 1.26.1
- Uses custom Block Entity for tracking usage
- Implements the Bed interface for proper sleep mechanics
- Fully compatible with any dimension
- Does NOT set player spawn point
